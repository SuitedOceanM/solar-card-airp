# 索拉利亚 · 数值与三大子系统设计（提案 v1）

> 用途：把数值框架落成可实施的规格。**属性 7 项（各满级 20）× 技能 21 项（7 属性 × 3 条线，各 0–5 级）**，三大子系统 = **魔法 / 网络战（黑入）/ 普通战斗**。
> 后两者按你的要求**参照赛博朋克**，参照物是手头已有的《高塔：2080》卡（已扒出其属性、技能与战斗结构）。
> 本文件是**提案**，等你确认后并入正式契约。

## 一、先对齐：赛博朋克参照物里到底有什么

从《高塔：2080》扒出来的实际结构（不是凭印象）：

| 项 | 2080 的做法 | 我们借不借 |
|---|---|---|
| 属性 | 缩写四项：**武 / 智 / 专 / 甲**，另有派生 **生（生命）/ 伤（伤害）** | ✅ 借"短属性表 + 派生值"的思路，但扩充到 6 项 |
| 技能 | **1–5 级**，每条技能写明：触发条件 → 核心属性 → 对抗面 → 等级裁定（高一级可尝试、高两级无从下手）→ 大成功/大失败效果 → 学习途径 | ✅ 全借，这是"偏中度"的关键 |
| 战斗 | **拍（beat）制**；单位数据卡格式：`名称｜档位｜武xx 智xx 专xx 甲xx｜生xx 伤xx｜服装｜武器｜义体｜职责` | ✅ 全借，直接换皮换名 |
| 群体对抗 | **威胁值**（3 人猎组=22，精锐=25，最高 28–32），且**加成必须在剧情里实际做到**才生效 | ✅ 借，防止敌人凭空开挂 |
| 网络战 | **RAM 资源** + 程序槽 + 连续入侵标记 + 入侵回执（能力/成功/说明/时间） | ✅ 借 |
| 义体 | 槽位 + 负荷 + 状态（正常/过载/故障/失效/禁用/降频）+ 同调适应 | ⚠ 简化：Solar 用**博格植入体**，不做产业链级复杂度 |
| 判定展示 | 对玩家**显式展示判定块**（FateCheck 被正则渲染成"⚡ 行动判定"折叠面板） | ✅ **借**——判定已改为强判定，正是要这个；改成终末地黄黑配色 + 我们自己的字段模板 |

## 二、属性（7 项，**各满级 20**）

七个属性各带三条技能线，构成 **7 × 3 = 21 项技能**的完整矩阵。**护甲不再是属性**，改为派生值（装备 + 体魄），属性位让给「战斗」。

| 属性 | 管什么 | 三条技能线 |
|---|---|---|
| **体魄** Physique | 能不能扛、能不能撑 | 力量 · 耐力 · 韧性 |
| **专注** Focus | 察觉、抗压、临场反应 | 感知 · 意志 · 反应 |
| **智力** Intellect | 判断、学识、谋划 | 分析 · 知识 · 策略 |
| **技术** Technical | 动手、侵入、治疗 | 工程 · 网络 · 医疗 |
| **口才** Social | 对人的一切 | 交涉 · 统御 · 欺骗 |
| **战斗** Combat | 一切交战 | 射击 · 格斗 · 战术 |
| **源质** Essence | 原生灵 / 魔法 | 施法 · 感应 · 操作 |

### 属性上限分三层

| 层级 | 上限 | 达成方式 |
|---|---|---|
| **常规** | **20** | 创建分配 + **经验点**逐步提升（20 已是"神一般的水平"） |
| **突破** | **25** | 只有 **技能芯片** 与 **古代遗物** 能推过 20——这是"碾压一切"的档位 |
| **种族特例** | 固定值 | **合成种开局固定 20 点智力**（其余属性照常分配） |

加点刻度**每点 +1**（不做"低于某值给负修正"，减少口算与展示负担）。
刻度参考：平民 5–8｜受训者 9–12｜专业人员 13–16｜顶尖 17–19｜20 = 神级｜21–25 = 芯片/遗物堆出来的碾压档。

> 25 点会直接把判定顶穿：属性 25×3 = 75，加满技能 25 = **目标值 100**，此时"失败"与"大失败"两档自然消失（见 task-breakdown §0.2 的档位规则）——这就是"碾压"的数学表现，不需要额外的无敌设定。

### 派生值（不占属性位）

| 派生 | 来源 | 给谁看 |
|---|---|---|
| 生命 | 体魄×2 + 成长修正 | UI 状态栏 |
| **护甲** | 装备 + 植入体（不再占属性位） | 战斗减伤 |
| 伤害 | 武器 + 力量系数（2080 里"伤害"就是独立派生项） | 战斗计算 |
| **源质储备** | 源质 × 系数 | 魔法资源（见 §4.1） |
| **终端带宽 RAM** | 技术 + 植入体 | 网络战资源（见 §4.2） |
| **暴露度** | 网络战失败累积（0–100） | 反追踪（见 §4.2） |
| 负荷 | 植入体 + 装备 | 限制堆叠 |
| 伤势 | 轻 / 中 / 重（沿用 2080 的健康事件结构） | 战斗与恢复 |
| 声望 / 关系 | 剧情累积 | 社会层 |

## 三、技能（21 项 = 7 属性 × 3 条线，各 0–5 级）

等级判定的定义权归属性，具体判定归技能。每项技能都写清"什么时候该判它"，避免出现"分析 vs 知识 vs 策略"这种含糊地带：

| 属性 | 技能 | 什么时候判 |
|---|---|---|
| 体魄 | **力量** | 破拆、推举、近距离硬压、扛重物 |
| 体魄 | **耐力** | 长距离移动、长时间作业、负重行军、憋气 |
| 体魄 | **韧性** | 抗伤、抗毒、抗病、抗疼痛、抗恶劣环境 |
| 专注 | **感知** | 观察、察觉埋伏、搜索、听声辨位、先手判定 |
| 专注 | **意志** | 抗恐惧、抗精神侵蚀、压力下维持专注（含施法稳定） |
| 专注 | **反应** | 闪避、临场应变、快速拔枪、抢拍 |
| 智力 | **分析** | 推理、破解谜题、判断真伪、读情报 |
| 智力 | **知识** | 学识、历史、文化、语言、辨认装备与阵营 |
| 智力 | **策略** | 谋划、布阵、资源调度、行动前的布局 |
| 技术 | **工程** | 维修、改装、制造、破拆、载具维护 |
| 技术 | **网络** | **网络战（即黑入）**：入侵、破解、程序、反追踪 |
| 技术 | **医疗** | 急救、治疗、手术、义体医学、毒理 |
| 口才 | **交涉** | 说服、谈判、议价、求助 |
| 口才 | **统御** | 指挥、威慑、带队、管理 |
| 口才 | **欺骗** | 撒谎、伪装、渗透、误导 |
| 战斗 | **射击** | 枪械、重武器、远程压制 |
| 战斗 | **格斗** | 近战、徒手、冷兵器、擒拿 |
| 战斗 | **战术** | 掩体利用、队形、交火指挥、战场判断 |
| 源质 | **施法** | 主动施放原生灵（自定义法术的核心判定） |
| 源质 | **感应** | 探知原生灵场、识别魔法痕迹、察觉异常 |
| 源质 | **操作** | 精细操控：维持多法术、远程操控、稳定源质输出 |

等级裁定沿用 2080 那套：**高一级可尝试但情境下调一档；高两级以上无从下手**，让技能等级有意义但不至于变成门禁。

### 技能获取途径（你定的四条）

| 途径 | 速度 | 可达上限 | 代价与风险 |
|---|---|---|---|
| **技能芯片** | 最快（又快又好） | 常见 1–3 级，高级芯片可到 4 | **未登记芯片极稀少**；**私人持有即为犯罪**；可能有后门、副作用、被追踪 |
| **课程 / 训练** | 慢（要时间与钱） | 常规 1–3 级 | 需要时间、学费、合格教官 |
| **义体** | 直接**给新技能**（不提等级） | 每个义体固定带 **2 个技能：1 主动 + 1 被动** | 占负荷、需同调、有故障与过载风险；技能内容可合理随机生成，**允许玩家提示**想走的方向 |
| **古代资料** | 极慢（研究与解读极难） | **可突破常规上限**（技能可超 5 级；属性可破 20） | 极稀有；必须 智力·知识 + 技术 才解读得动 |

> **义体不再"提等级"，而是"加技能"**——这条很关键：义体给的是"这具身体能做的事"（主动技能如内置武器/光学迷彩，被动如夜视/疼痛抑制），而不是让你原本练的技能变强。所以义体、技能芯片、课程三者不会互相替代，各自都有存在意义。

这四条天然带出社会层玩法：芯片黑市、登记制度、执法查抄、古代资料的争夺——不需要额外编设定，它们直接从世界书里长出来。

## 四、三大子系统

三者**共用**：同一套判定制式（COC 式 d100 掷低，**目标值 = 属性×3 + 技能×5 + 修正，封顶 85**，**五档结果**，详见 task-breakdown §0.2）、7 项属性（满级 20）+ 21 项技能、同一份骰源。
三者**各自不同**：资源、对抗面、失控代价。

### 4.1 魔法（原生灵 / 源质）—— **v1 走自定义法术**

**设定依据**：世界书《原生灵科技》——魔法即科学，原生灵场 + 源质，星晶供能；《泰伦亚人·原生灵三阶状态》已定义出力阶段与**卡路里透支**代价。

**已定**：v1 **不做固定法术列表**，玩家现场描述施法意图，由 GM 按下面的规则定价。魔法资料书你之后给，届时按 §4.1.2 的接入点接进来，不用改引擎。

#### 4.1.1 自定义法术的现场定价（v1 规则）

```
资源：源质储备（可消耗，靠休整/星晶补充）
出力阶：基底常态 → 战术流动态 → 过载激化 → 沸腾态（沿用世界书原生设定）
判定：**源质 + 施法**；探测与辨识用 **源质 + 感应**；维持多法术、远程操控用 **源质 + 操作**；对无生命/环境目标可降档或免判
代价：出力阶 ≥ 战术流动态 起累积卡路里透支；沸腾态后强制脱力

定价三步：
  ① 归类：作用面（伤害 / 防护 / 控制 / 感知 / 治疗 / 改造）× 规模（个人 / 小范围 / 区域）× 持续（瞬时 / 数拍 / 长期）
  ② 定价：源质消耗 = 基础值 × 规模系数；同时得出"所需最低出力阶"
  ③ 记录：本次施法进入"自创法术"记录
```

**关键设计：自创法术会被记住。** 同一个法术第二次使用时，源质消耗与判定难度都下调——玩家于是会自然长出自己的"私人法术书"。这既是 v1 的成长钩子，也正好是资料书接入时的映射对象（自创法术 → 正式法术条目）。

#### 4.1.2 魔法资料书接入契约（预留，等你的资料书）

资料书到位后只需提供一张表，引擎按字段映射即可，不动判定与 UI：

| 字段 | 说明 |
|---|---|
| 法术名 / 别名 | 检索与显示 |
| 学派 / 来源 | 原生灵分类，对应世界书条目 |
| 最低出力阶 | 基底常态 / 战术流动态 / 过载激化 / 沸腾态 |
| 源质消耗 | 数值或公式 |
| 效果 / 规模 / 持续 | 用于判定与展示 |
| 代价 | 透支量、副作用、冷却 |
| 前置 | 属性/技能门槛、装备、许可 |
| 判定 | 用哪项属性+技能、对抗面 |

**这份资料书和世界书走同一个"设定接入层"**（`getLore()` / `getSpells()` 两个 provider），所以它和 T3.3 是同一处代码改动——这也是为什么现在不急，接口留好就行。

### 4.2 网络战（黑入 / 旧网 / 深网）

**设定依据**：世界书《技术背景·行星旧网与深网体系》（2602 字）、《旧网攻防与黑客战术》《单兵战术·现实短距战术网络入侵》《网安局·黑墙网关》。

```
资源：终端带宽 RAM（每次入侵/程序消耗，战斗或长休后恢复）
程序槽：有限，需预先装载
进攻判定：技术 + 网络，对抗面读目标的技术·网络；多人 / 集群系统读威胁值

防护侧（不是"黑冰"，官方叫 ICE网络自动防护协议）：
  · 本质是防火墙，**一般不主动杀伤**
  · 进攻方硬闯失败 → 被记录行为特征 → 暴露度上升

进攻侧 = 攻击脚本：
  · 敌方与玩家都能装载多种脚本，**植入体过载只是其中一种**
  · 植入体过载对**使用博格植入体的玩家杀伤力非常有限**（博格系抗性强）

反追踪（暴露度 0–100）：
  · **>50 开始反追踪**，一般 **3 回合内查到人**（默认 1 回合 = 5 分钟）
  · 玩家可用**防御性网络协议 + 智力系技能（分析 / 策略）**延长被查到的回合数
  · **合成种玩家永远无法被反追踪**；除非对手也是合成种或真龙种

边界：黑墙 / 旧网 / 失控 AI 属"剧情级"目标，需专门装备与剧情依据，不能靠技能等级硬闯
```

注意进攻与防守**用的是不同属性**：侵入别人是 **技术·网络**（动手），拖住追踪是 **智力·分析 / 策略**（动脑）。这让"技术型"和"智力型"黑客是两种不同玩法。

参照赛博朋克的地方：RAM、程序槽、连续入侵、反追踪。**不同的是"魔法科技共生"**——深层网络在世界书里连着"深层梦境/阈限空间"，所以网络战可以出现超现实场景，这是 Solar 独有的味道。

### 4.3 普通战斗（枪战 / 近战）

```
节拍：拍制（每拍一次行动），沿用 2080
判定：枪战 = **战斗 + 射击**；近战 = **战斗 + 格斗**；战场调度与掩体利用 = **战斗 + 战术**（谋划层面另可叠 智力·策略 的情境加值，不叠属性）
计算：伤害 vs 护甲 → 生命；伤势分轻/中/重，重伤有持续影响
单位：沿用 2080 数据卡格式 —— 名称｜档位(杂兵/职业/精英/头目)｜属性 ＋ 生命/伤害｜装备｜行为约束
群体：威胁值用于包围/突围/伏击等整体判定，加成必须在剧情里实际做到
```

近战补偿：世界书给了《泰伦亚人·生理天赋》（血沸、肉体碾压），可以名正言顺地让近战在高科技枪械世界里有一席之地。

## 五、三个子系统怎么共存（同一次遭遇里）

典型场景：玩家闯进一座旧设施——先黑入（关掉摄像头）→ 中途被发现 → 转入战斗（枪战）→ 打不过就动魔法（原生灵爆发）→ 付出卡路里透支代价撤退。

所以引擎要能**在同一回合内串联多个子系统**，规则：

1. 每回合仍受判定次数上限约束：**常规 1–3 次判定，大战斗才放开到"每拍一次"**——三个子系统不会让骰子变多，只会让同一回合的局势更复杂。
2. 三个子系统共用一个"当前遭遇"状态（在场单位、位置、暴露度、出力阶）。
3. 跨系统的因果必须写进正文（黑入失败导致的反追踪，会在战斗中被敌人利用）。

### 还需要你定的

1. **博格与传统义体是否也互斥**：世界书明写"博格吃掉老式脑机"，但没写它与**传统金属义体**的关系。我倾向"可共存但负荷叠加、且同调/维护更麻烦"，需要你确认（见 §9.3.1）。

## 九、成长经济 · 危险阶梯 · 脚本清单 · 尺度开关 · 创建向导（本轮新增）

### 9.1 成长经济

| 货币 / 途径 | 用途 | 节奏与上限 | 来源 |
|---|---|---|---|
| **技能点** | 提升**技能**（21 项，各 0–5） | **3–5 场战斗给 1 点** | 战斗结算 |
| **经验点** | 提升**属性**（7 项，上限 **20**） | 里程碑 / 任务 / 训练，比技能点慢得多 | 剧情与长期活动 |
| **技能芯片** | 直接给技能等级 | **普通芯片随处可见**；未登记芯片稀少；**强力芯片多在军方与特殊机关手里** | 商店 / 黑市 / 缴获 |
| **旧网下载** | 直接学会技能（**这就是"旧网"在设定里的意义**） | 看节点与权限，越好的越难找 | 深网 / 档案馆 / 遗迹节点 |
| **义体** | 给 **2 个新技能**（1 主动 + 1 被动），不提等级 | 每个义体固定 2 项，可合理随机生成、允许玩家提示方向 | 义体商 / 军用渠道 |
| **古代遗物** | 唯一能把属性推过 20（到 **25**）的东西 | **极稀有**，只在遗迹深处小概率出现 | 古代遗迹 |

> 20 点的定位是**现世人神**：经验点能到 20，意味着长期玩家靠纯练度可以封神；25 点只属于遗迹运气，不是规划出来的路线。

### 9.2 古代遗迹：危险阶梯与产出

```
环境：失控工厂——自动化设施仍在自行运转，防御系统没有主人，也没有停机键
常驻威胁：长期滞留的失控实验体 / 魔物 / 遗迹 AI

难度曲线：
  前中期 → 玩家会被遗迹 BOSS 秒（明写死，不靠数值微调）
  后期   → 才有资格谈进出
  设计底线：遗迹不是副本，是事故现场

产出路径：
  击败遗迹 BOSS → 可能拿到【通行密钥】
    → 用它打开遗迹的仓库 / 档案室
      → 小概率出现可用的【古代遗物】（属性可破 20）
      → 或出现【古代资料】（技能可破 5 级，但解读极慢）
```

这条阶梯同时解释了"25 点档怎么来"：不是刷出来的，是赌命赌出来的。

### 9.3 核心脚本清单（按执行端分类）

你说"先这 5 个"，我按 **5 个攻击脚本 + 1 个定位辅助**来组织（编号 1 的"网络定位"归为辅助，不算杀伤脚本；如果你本意是把它也算进 5 个里，说一声我改）：

| 类 | 脚本 | 执行端 | 效果 |
|---|---|---|---|
| **辅助** | 网络定位 Ping / Trace | 敌方局域网节点与神经芯片广播 | 扫描锁定掩体后所有敌军坐标，在战术目镜与数据链里瞬间高亮 |
| **脑机过载** | 精神撕裂 Synapse Tear | 生物脑机接口与神经触点 | 反向灌注高压致乱信号 → 神经剧痛、感官剥夺、认知暴走，**敌我不分向身旁队友扫射** |
| **脑机过载** | 突触熔毁 Synapse Meltdown | 脑干与核心植入体 | **致死级**：脑出血、神经炭化、瞬间脑死亡。表现是"人还站着，头盔缝里渗出两道血丝，然后像被抽掉线的人偶一样栽倒" |
| **义体过载** | 义体短路 Short Circuit | 机械义肢与动力伺服电机 | 注入瞬态浪涌 → 伺服电机电弧自燃、关节卡死、小规模硬件爆破 |
| **义体过载** | 义体重启 System Reboot | 动力甲火控与外骨骼控制核 | 注入重置死循环 → 外骨骼与动能辅助**瘫痪 5–10 秒**硬直 |
| **总线劫持** | 自尽协议 Suicide Override | 神经运动总线与武器控制接口 | 夺取义肢与神经反射最高控制权 → **强制目标向自身要害扣扳机** |

**博格植入体与脑机是互斥的**——这不是平衡性规则，是设定里的物理事实。世界书《博格植入体·植入与同化机制》原文：若使用者原本装有**老式物理脑机接口（BCI）**，博格核心可如 U 盘般直插；随后纳米云会**从分子层面"吃掉"并拆解原有的物理脑机设备，直至其完全消失**，用纳米神经元取而代之。

于是抗性表变成这样：

| 目标状态 | 脑机过载（精神撕裂 / 突触熔毁） | 义体过载（短路 / 重启） | 总线劫持（自尽协议） |
|---|---|---|---|
| **老式物理脑机 + 传统义体** | 正常命中（执行端就是它的接口） | 正常命中 | 正常命中 |
| **博格植入体** | **极难命中**（纳米神经元 + AGI 实时拦截） | **基本无效**（无伺服电机 / 无外骨骼控制核） | **极难命中**（神经系统不是可劫持的总线） |

博格路线的代价写在世界书里：**贪食诅咒**——纳米云全部能源榨自宿主卡路里，开一次子弹时间或做一次断肢接续，血糖立刻见底，必须随身携带高热量食物。**它不是"更强"，是"换了活法"**。

### 9.3.1 博格路线（一并进创建向导）

世界书里博格植入体的四个特征是现成的系统素材：

| 特征 | 系统含义 |
|---|---|
| **人造源质回路** | 让本来没有魔法潜能的种族（尤其纯血人类种）**也能安全稳定施法**——这是"博格 = 能玩魔法"的设定依据 |
| **AGI 伴生智脑** | 脑内常驻 AI：思维级交流、加速逻辑、**协助接入并破解局域网**、过载运算烧毁敌方载具控制电脑 |
| **子弹时间** | 神经反射加速，可躲超音速弹丸（战斗系统里的大杀器，代价是血糖） |
| **极端再生 / 破体义肢** | 断肢几秒接续；绝境时纳米强行破体凝成临时义体 |

所以在创建向导里，**"装不装博格"是一个会影响全部三个子系统的重大选择**：装了能施法、能打电子战、能进子弹时间，但要背贪食诅咒，而且**与老式脑机路线互斥**（是否连传统金属义体也一并放弃，见 §7 待定项）。

### 9.4 尺度开关：两个独立量表，各两档（简化版）

按你的意见把三档砍成两档——**分档的困难主要来自"16+ 到底算什么"，去掉中间档就没了这个问题**：

| 量表 | 两档 | 每档怎么写 |
|---|---|---|
| **NSFW** | **克制** / **直白** | 克制：不出现直接描写，用暗示、淡出、事后提及（即原来的"全年龄 + 16+"合并进这一档）；直白：可有直接情色描写 |
| **直白暴力** | **克制** / **直白** | 克制：血腥点到为止，不写致残与处决细节；直白：可有血腥、致残、处决、酷刑的直接描写 |

两个量表**独立设置**（可以"暴力直白 + NSFW 克制"，也可以反过来），各自影响提示词约束、设定条目路由、UI 面板显隐。

**并且：即使在直白档，也保留"逐项跳过"**——玩家任何时候都能对当前这个场景说"跳过 / 淡出"，偏好会被记住。这样"两档"不会牺牲控制权，反而比三档更好理解。
