## 一、这一包是什么

按 `task-breakdown.md` 的 M1 定义，把九条会那套工程 fork 成索拉利亚的**可运行空壳**：
在酒馆里能展开全屏终端风界面、能调通"正文走当前预设"的生成链路、能存读档，**不含玩法**。

## 二、怎么跑

### 1) 本地看（不需要酒馆）

双击 `preview/mounted.html`（自动点一次"展开"，直接进全屏界面）或 `preview/launcher.html`（只看楼层启动块）。

- `preview/assets/vue.global.prod.js` 是本地补的 Vue 运行时（酒馆里由助手 iframe 提供）。
- 页面里的 `pinia` 仍从 `testingcf.jsdelivr.net` 拉取，所以**本地预览需要能上网**。
- 本地没有酒馆助手全局，所以底栏会显示 `CHAT-VARS N/A`、`GEN N/A`，生成/存取会提示"需在酒馆内运行"——这是预期行为。

### 2) 在酒馆里跑

把 `dist/索拉利亚-状态栏.html` 推到你的仓库（走 jsDelivr），然后按九条会同款方式加载：

```html
<StatusPlaceHolderImpl/>
```
```js
// 正则（显示层）：整条消息换成加载代码
$('body').load('https://testingcf.jsdelivr.net/gh/<你的仓库>/<分支>@<commit>/dist/solaria/界面/状态栏/index.html')
```

另配一条 **promptOnly** 的隐藏正则把 `<StatusPlaceHolderImpl/>` 从提示词里去掉（同九条会两条正则的分工）。
楼层里会出现「◤ 展 开 · 索 拉 利 亚」按钮，点开即全屏。

### 3) 自己构建

```powershell
cd <工程目录>
pnpm install
pnpm build      # 产出 dist/solaria/界面/状态栏/index.html（单文件）
```

工程目录里保留了完整模板链（webpack 多入口、单文件 HTML 内联、Vue 外部化为全局、pinia 走 CDN ESM、tavern_sync 实时同步）。
